## Висновок

Серед трьох навчальних реалізацій алгоритм Боєра–Мура виявився найкращим завдяки швидкому пошуку довгих підрядків.
На короткому підрядку `))*` швидшим був алгоритм Кнута-Морріса-Пратта, а на `1536` результати алгоритмів Боєра–Мура і Кнута-Морріса-Пратта виявилися близькими.
Алгоритм Рабіна–Карпа був найповільнішим у всіх наведених тестах.

*\* Це порівняння конкретних навчальних реалізацій.*

*\*\* Вбудований `str.find()` значно перевершує усі навчальні реалізації за швидкістю завдяки використанню оптимізованого коду CPython.*
